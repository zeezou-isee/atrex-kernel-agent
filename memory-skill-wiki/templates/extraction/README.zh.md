# templates/extraction/ — 提取指南目录 (auto-scanned)

[English](README.md) · **中文**

这里放**抽取记录时**要遵循的指南。抽取的两条路径(后台增量 `run_extraction.sh`
和最终 `/done-run`)都会**自动读取本目录下的所有 `.md`** 作为"怎么写"的规范。

## 怎么扩展
- **直接把新的 `.md` 丢进这个目录**即可,下次抽取就会自动带上,**零改代码、不用重装**。
- 修改现有指南直接改文件内容,**即时生效**(skill 是软链,运行时读当前内容)。
- 改完记得**重新上传 OSS** 才会同步过去(本地改动不会自动同步)。

## 扫描规则
- 只读 `*.md`。
- **忽略** 任何 `README*` 文件、以及以 `_` 或 `.` 开头的文件
  (所以想临时停用某个指南,给它改名加个 `_` 前缀即可)。
