# templates/summary/ — 总结骨架目录 (auto-scanned)

[English](README.md) · **中文**

这里放 `/done-run` 生成**会话总结**时用的骨架/模板。`/done-run` 会**自动读取本目录下
的所有 `.md`** 作为可用骨架;若有多个,由它按算子/场景挑最合适的一个来填。

## 怎么扩展
- **直接把新的骨架 `.md` 丢进这个目录**即可(例如给不同算子/不同硬件准备不同骨架),
  下次 `/done-run` 自动可选,**零改代码、不用重装**。
- 修改现有骨架直接改内容,**即时生效**。
- 改完记得**重新上传 OSS** 才会同步过去。

## 扫描规则
- 只读 `*.md`。
- **忽略** 任何 `README*` 文件、以及以 `_` 或 `.` 开头的文件。
